# 🎲 Dice-cise

Permainan latihan kognitif (ejaan) + senaman fizikal untuk Unit Fisioterapi.

- **Satu fail sahaja**: `index.html`. Buka terus dalam browser. Tiada backend, tiada login.
- Live: https://mohdadhanawawi.github.io/dise-cise/
- Mesra tablet & skrin TV. Butang ⛶ untuk skrin penuh.

## Cara main
1. Pilih **Tahap Kognitif**: 1 = 1 perkataan (4–6 huruf), 2 = 2 perkataan (7–9 huruf), 3 = 3 perkataan (10–12 huruf).
2. Pilih **Tahap Keupayaan**: 1 Perlu Bantuan (±70%), 2 Bantuan Minima (±30%), 3 Berdikari. Ini menentukan jenis senaman.
3. **Baling Dadu Kategori**: 1 Kenderaan · 2 Makanan · 3 Tempat · 4 Personaliti · 5 Objek · 6 Baling Semula.
4. Vokal dipaparkan siap. Pemain teka **konsonan** sahaja, kiri → kanan. Butang 💡 tunjuk gambar petunjuk.
5. Salah → **Dadu Hukuman** (1–2, 3–4, 5–6 = tiga senaman ikut tahap keupayaan).
   Ulangan = bilangan huruf (ayat penuh atau perkataan semasa), boleh dihadkan (Max 3–10) di skrin mula.
6. **🏁 Tamat Sesi** untuk ringkasan.

## Ubah suai
- Perkataan: objek `WORDS`. Tahap: `LEVELS`. Senaman: `EXERCISES` dan `ABILITY`.
